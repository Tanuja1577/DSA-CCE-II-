Project Description

This project focuses on implementing Stack and Queue data structures in C++ using arrays and linked lists. It is developed as part of the DSA CCE II activity. Git and GitHub are used to manage the project files, track changes, and store the source code in a repository.

Programs Implemented

1. Stack Using Array

File: "Stack-Using-Array/stack_array.cpp"

Operations:

- Push – Adds an element to the stack.
- Pop – Removes the top element.
- Display – Shows the stack elements.
- Exit – Terminates the program.

2. Queue Using Array

File: "Queue-Using-Array/queue_array.cpp"

Operations:

- Enqueue – Inserts an element into the queue.
- Dequeue – Removes an element from the queue.
- Display – Shows the queue elements.
- Exit – Terminates the program.

3. Stack Using Linked List

File: "Stack-Using-Linked-List/stack_linked_list.cpp"

Operations:

- Push – Inserts a new node at the top.
- Pop – Deletes the top node.
- Display – Prints the stack elements.
- Exit – Terminates the program.

4. Queue Using Linked List

File: "Queue-Using-Linked-List/queue_linked_list.cpp"

Operations:

- Enqueue – Adds a new node at the rear.
- Dequeue – Removes a node from the front.
- Display – Prints the queue elements.
- Exit – Terminates the program.

Concepts Used

- Stack: Follows the LIFO (Last In, First Out) principle.
- Queue: Follows the FIFO (First In, First Out) principle.
- Arrays: Store elements in continuous memory locations.
- Linked Lists: Store elements using connected nodes.
- Classes and Objects: Organize the program using object-oriented concepts.
- Dynamic Memory Allocation: Allocates memory during program execution.
- Version Control: Git tracks changes in the source code.
- GitHub Repository: Stores and shares the project online.

Software Requirements

- Visual Studio Code for writing and editing code.
- GCC/G++ compiler for compiling and running C++ programs.
- Git for version control.
- GitHub account for creating and maintaining the repository.

Conclusion

This project demonstrates the working of Stack and Queue using both arrays and linked lists. It provides practical knowledge of basic data structures and their operations in C++. Git and GitHub help organize the project files, track code changes, and maintain the source code in an online repository.
